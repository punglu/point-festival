# 디자인 고도화 확정 사항 (Phase 3 적용)

> **협의일:** 2026-03-30
> **적용 시점:** Phase 3 (User Dashboard FE) 진입 시
> **기반:** design-v2-user.html / design-v2-admin.html 프로토타입

---

## 1. 페이지 구조 변경

### 게이트 페이지(index.html) 폐기
- `/` 접속 시 바로 user 페이지(플레이어 선택 화면)로 진입
- 별도 진입 선택 화면 없음

### 관리자 진입 (이중 접근)
- **방법 1:** URL 직접 입력 (`/admin`)
- **방법 2:** user 페이지 어딘가에 숨겨진 진입점 (예: 로고 길게 누르기, 설정 아이콘 등)
- 두 가지 모두 적용

### 관리자 페이지 멀티 페이지 분리
- **사용자 관리** 탭/페이지: 아이 등록, PIN 설정, 잠금 해제, 로그인 기록
- **미션 관리** 탭/페이지: Quest Control, 미션 CRUD, 일괄 복제/삭제, 제안 검토, 응원 메시지
- 하단 네비바로 전환 (대시보드 / 사용자 / 알림 / 설정)

## 2. 동심 자극 요소 (전체 적용)

### 마인크래프트 픽셀 아트 스타일
- 프로필 영역, 아이콘, 배경 패턴에 픽셀 도트 질감 활용
- 8bit 느낌의 보더, 각진 그림자

### 레벨업 / 경험치 바 게임 요소
- 포인트를 "경험치(EXP)"로 시각화
- 프로필 카드에 레벨 표시 (예: Lv.3, 총 누적 포인트 기반)
- 경험치 바 (현재 레벨 진행률) 프로필 하단에 배치

### 이모지 / 캐릭터 아이콘 크게
- 미션 상태, 버튼, 섹션 헤더에 큼직한 이모지/캐릭터 활용
- 아이 프로필 영역에 커스텀 아바타 또는 대형 이모지

### 미션 완료 시 축하 애니메이션
- 승인 완료 시 confetti(폭죽) 또는 별 파티클 애니메이션
- "레벨업!" 배너 표시 (포인트 누적 임계치 도달 시)

---

## 3. 미션 상태 직관성 개선

### 진행률 바 (3단계)
기존 텍스트 상태 → 시각적 프로그레스 바로 변경:

```
[요청] ──●────────── [확인중] ──────●──── [완료!]
```

| 기존 상태 | 새 표현 | 진행률 바 위치 |
|---|---|---|
| active (진행 중) | "도전 중!" | 0% (시작) |
| pending_approval (승인 대기) | "확인 중..." | 66% (2/3) |
| completed (완료) | "완료!" + 축하 | 100% |
| failed (실패) | "다음에 도전!" | 빨간색 표시 |
| rejected (거절) | "다시 생각해보자" | 회색 표시 |

### 포인트 직관성
- 미션 카드에 포인트를 게임 코인 아이콘 + 큰 숫자로 표시
- 프로필의 총 포인트를 "보물상자" 아이콘과 함께 강조

---

## 4. 레이아웃 확정 (user 페이지)

### 유지 항목
- 하단 네비게이션 바 (홈 / 순위)
- 스토리 카드 (아빠 / 엄마 — 2명 고정, "추가" 버튼 제거)
- 탭 구조 (미션 / 제안하기 / 답장)
- 글래스모피즘 헤더
- PIN 로그인 오버레이 (기존 동작 100% 보존)

### 변경 항목
- 스토리 카드에서 "+" 추가 카드 제거
- 미션 카드 내 텍스트 상태 → 진행률 바
- 프로필 카드에 레벨 + 경험치 바 추가
- 미션 완료 시 축하 애니메이션 추가
