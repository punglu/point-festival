## 📝 테스트 시나리오

### 시나리오 1: 신규 사용자 등록 및 첫 로그인
1. admin.html 접속 → 관리자 로그인
2. 사용자 관리 → 이름 "테스트아이" + PIN "1234" 입력
3. ➕ 등록 버튼 클릭
4. user.html 접속 → "테스트아이" 선택
5. PIN 1234 입력 → 로그인 성공
6. 자동 로그인 체크 → 다음 접속 시 자동 로그인

### 시나리오 2: 미션 생성 및 완료
1. admin.html → 미션 생성
2. "숙제하기" +10P 엄마 메시지 "화이팅!"
3. user.html → 미션 확인
4. admin.html → 승인 버튼 → 폭죽 효과
5. user.html → 현재 보유 +10P 확인

### 시나리오 3: 포인트 차감
1. admin.html → ➖ 차감 버튼
2. 금액 5, 사유 "간식" 입력
3. 차감하기 → 현재 보유 -5P
4. 사용 내역 아코디언 → "간식 -5P" 확인

### 시나리오 4: 로그인 5회 실패
1. user.html → 아이 선택
2. 틀린 PIN 5번 입력
3. "5회 실패하여 5분간 잠금" 메시지
4. 다시 로그인 시도 → "N분 후 재시도" 알림
5. admin.html → 🔓 잠금해제
6. user.html → 정상 로그인 가능

### 시나리오 5: 모두의 진행현황 확인
1. user.html → 로그인
2. 화면 하단 "🏆 모두의 진행현황" 섹션 확인
3. 모든 아이들 카드 표시
4. 내 계정에 "내 계정" 뱃지 확인
5. 각 아이별 배정/완료/보유 통계 확인
6. 최근 미션 미리보기 확인
7. 접기 버튼 → 섹션 숨김
8. 펼치기 버튼 → 섹션 표시

### 시나리오 6: 답글 긴 텍스트
1. admin.html → 피드백 답글 작성
2. 긴 텍스트 입력 (100자 이상)
3. user.html → 답글 확인
4. **✨ 답글이 자동으로 줄바꿈되어 전체 내용 표시**
5. 높이가 내용에 맞게 자동 조정
